# 去 AI 味改写规则（公告推文专用）

## 一、先搞清楚：哪些"AI 味"不该改

自动检测脚本的词库是为**自媒体文**设计的，套到公告体上会产生两类**误判**。不要为了提分去修它们。

| 扣分项 | 脚本判据 | 为什么公告体不该改 |
|---|---|---|
| 缺乏个性化声音 | 全文无"我/我们" | 公告转述出现第一人称反而不专业。政务通告腔是这个体裁的正确姿态 |
| 标题 emoji 滥用 | 统计到 6 个 emoji | 💡 提示卡、🖼 推图占位、📊 资料位——都是排版组件图标，不是 AI 装饰 |

**判断标准**：这个"毛病"换个真人编辑来写，他也会这么写吗？会 → 不动。

---

## 二、真正要改的四类问题

### 1. 公文/AI 连接词

这些词不进任何词库，但读起来就是"不是人写的"：

| 套话 | 改法 |
|---|---|
| 需要提醒的是 | 直接删，后面的话单独成段 |
| 值得注意的是 | 直接删 |
| 综上所述 / 总而言之 | 直接删 |
| 首先…其次…最后 | 改成并列短句，或按重要性排序后平铺 |
| 希望能帮到你 / 希望对你有帮助 | 直接删 |
| 让我们一起… | 直接删 |

### 2. 句式重复（B1 型）

同一句式在相邻段落反复开头，是最明显的机器痕迹。

**典型："本次"开头堆叠。**

```
❌ 本次招聘的用人单位共5家，分别为……
   本次考试设定1:3开考比例……
   本次公开招聘卫生健康系统事业单位工作人员10名……
```

改法：保留必要的限定（如标题下第一句），其余删掉限定词。

```
✅ 用人单位共5家，分别为……
✅ 考试设定1:3开考比例……
```

**自查方法**：统计全文某个词的出现次数，超过 3 次就逐处检查是否可删。

### 3. 长段（违反公众号短段原则）

超过 4 行的段落一律拆。拆分点通常就在"需要提醒的是"这类连接词的位置——**删掉连接词就是天然的拆段点**。

### 4. 指向不明的模糊表述

| 模糊写法 | 改法 |
|---|---|
| 具体到岗位仍以学历门槛为准 | 仍以**岗位表**的学历要求为准（指向上一步的推图） |
| 请及时关注相关通知 | 点名具体平台或日期 |
| 各方面条件都比较优厚 | 换成公告原文的具体表述 |

## 三、字数压缩技巧

超 1500 字时按此顺序砍：

1. **合并重复限定**：同一章内重复出现的"本次""该岗位"删掉冗余的
2. **专业需求表只留量大方向**：其余用一句"具体以岗位表为准"带过
3. **删除背景性描述**：单位简介、历史沿革、政策口号——读者不关心
4. **长句拆短但总长压缩**：把"应聘人员须在报名首日以前（不包括报名首日）取得相应毕业证书、学位证书，以及岗位要求的专业技术资格或职业资格"压缩为"须在报名首日以前取得毕业证、学位证及岗位要求的资格证"

**不要靠删信息点来压字数**——宁可略微超一点，也不能少一个决策要素。

- [ ] 有没有连续三段用同一个词开头？
- [ ] 有没有"总结一下""一句话说"这类概括句？（用户明确要求删）
- [ ] 有没有把官方原文的限定词弄丢？（"应聘人员""不包括报名首日"这类）
- [ ] 数字和日期有没有被改写成模糊表述？
