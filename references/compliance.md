# 合规自检清单（招考公告推文专用）

发布前逐条过。装了 `publish-safety-officer` skill 就调它跑一遍，本清单作为兜底与补充。

---

## 一、平台导流红线（招聘类推文最高频的翻车点）

| 风险动作 | 判定 | 处理 |
|---|---|---|
| 推图/正文写"关注领取资料""转发后领取""扫码进群领" | **诱导关注 / 诱导分享，会被限流** | 推文里的占位文案保持中性；同时提示用户**图片本身**也不能带这类文字 |
| 引导去官方源文公告（"识别查看源文公告""去源文取一份"）| **本号不采用** | 一律改为内部引导：`领取岗位表` / `领取报名登记表` / `备考资料`。需要"以官方为准"时写成数据核对语境的一句话 |
| 内部引导领取岗位表 / 报名登记表 / 备考资料 | 合规 | 保留，动词用「领取/查收/自取」 |
| 文末放微信号 / 个人二维码 / 外链把人带出平台 | 内容导流，违规 | 删除 |
| 集赞、转发可见、关注后回复关键词 | 违规 | 删除 |

## 二、广告法绝对化用语

招聘/考编类推文虽非商业广告，但涉及机构推广时同样适用。逐字搜以下词：

**绝对化**：最、最好、最优、第一、唯一、首个、顶级、极致、100%、全网、国家级、世界级

**效果承诺**（考编类高危）：
- ❌ 包过、保过、包上岸、保证录取
- ❌ 通过率 XX%（无第三方审计依据不得宣称）
- ❌ 内部指标、内部关系、保过班
- ❌ "考不上全额退"这类保本承诺（需核对是否真有能力兑现）

**改法**：换成过程性表述——"覆盖历年高频考点""按岗位专业分方向备课"。

## 三、事实一致性核对（逐项打勾）

- [ ] 岗位数、招聘人数、用人单位数与职位表**完全一致**
- [ ] 所有日期时间（报名/确认/笔试/面试）与公告原文**逐字核对**
- [ ] 开考比例、面试入围比例、合格线数字无误，两个不同比例已区分表述
- [ ] 年龄口径的出生日期换算重新验算（按**报名首日**倒推，不是发布日）
- [ ] 学历、专业、执业资格要求未被简化到失准
- [ ] 服务年限、试用期表述与原文一致

**验收方式**：把推文里的每个数字与 `公告正文.txt` + 职位表 dump 对照一遍。

---

## 四、不得越界的内容

| 禁止 | 原因 |
|---|---|
| 写入公告**未提及**的信息 | 典型：历年公告有"三支一扶加10分"，本年公告没提 → 不写。写了会让读者误判 |
| 把历年考情写成本次的确定安排 | 必须挂在"以官方发布的笔试公告为准"提示下 |
| 把 A 类公告的规则套到 B 类 | 如省统考（1:5 进面）与自主招聘（1:3）规则不同，不可混用 |
| 编造考情、分数线、报录比 | 检索不到就跳过，不编 |
| 评价具体岗位"好考/难考""性价比高" | 属主观判断，易引发争议；用事实型反差替代 |

## 五、AI 生成痕迹

低质 AI 痕迹会被平台识别限流。对照 `references/rewrite-rules.md` 处理：

- [ ] 无"本文看点""综上所述""需要提醒的是"等套话
- [ ] 无句式重复（同一词/句式不连续堆叠）
- [ ] 段落均 ≤4 行
- [ ] 有具体的数字、日期、单位名（AI 的典型特征是空泛）

---

## 六、考编类特别提示（广东视角）

默认广东省视角撰写。涉及以下内容时注意口径：

- **广东省考**、**深圳市考**、**广东事业单位统考**是三套独立规则，比例、科目、时间均不同，不可互相套用
- 事业单位统考：1:5 进面、面试合格线 70
- 自主招聘：常见 1:3 开考、1:3 进面、笔试合格线 60、面试合格线 70
- 引述考情时注明**批次年份**，避免读者误读为现行规则
