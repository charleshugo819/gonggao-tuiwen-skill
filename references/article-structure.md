# 招聘公告推文 · 结构与写作规范

## 一、根本原则

招聘公告推文的读者只有两个问题：**我够不够格**、**我要做什么**。

所有结构安排都服务于这两件事。文采不重要，信息顺序才重要。

**读者决策链（章节顺序必须服从它）**：

```
是不是编制 → 招多少人 → 我够不够格 → 岗位在哪 → 怎么报 → 有什么坑
```

任何一个环节的信息被拆散到全文两头，读者就会在流程段白读一遍才发现自己不符合条件——这是完读率最典型的流失点。

---

## 二、三章结构模板

```
【前言】报名时间 + 报名方式（1段，≤60字）
   ↓
【推图位】领取岗位表
   ↓
01 公告提要        HIGHLIGHTS
   ├ 三列数据卡：岗位数 / 招聘人数 / 用人单位数
   ├ 用人单位名单（一句话列全）
   ├ ★ 学历门槛（几个要研究生、几个放宽至本科）—— 必须在此，且醒目
   ├ 待遇 / 服务年限
   ├ 专业需求表（按需求量排序，只列大的）
   ├ 执业资格 / 证书提示
   └ 【推图位】领取岗位表
   ↓
02 报名与考试安排   SCHEDULE
   ├ 时间节点表（报名 / 报名确认 / 笔试 / 面试）
   │    └ "报名确认"行必须视觉强调（红字加粗），漏做=报名失败
   ├ 报名确认提示卡（点明"报名和确认是两件事"）
   ├ 报名期间可改岗位（报名操作类，属本章不属资格章）
   ├ 开考比例
   ├ 笔试内容 + 笔试考情对比表 + 免责提示
   ├ 面试规则
   └ 总成绩公式
   ↓
03 报考资格        QUALIFICATIONS
   ├ 招聘对象 / 学历与证书要求（明确取得时点）
   ├ 年龄怎么算（周岁 ↔ 出生日期，按报名首日口径）
   ├ 应届生类别
   └ 不得报考情形
   ↓
【收束段】钉住两个关键日期
   ↓
【推图位】备考资料
```

### 章节内顺序的三个易错点

1. **学历门槛不能排在第 4 位之后**。"8个岗位要研究生、只有1个本科岗"直接决定多数读者是否继续读。若排在"招聘对象为本科及以上"之后，读者刚觉得有戏就发现只有 1 个本科岗，心理落差大。把门槛前置，或在该段末尾追加一句消解落差：
   > 本科及以上是公告设定的最低口径，具体到岗位仍以岗位表的学历要求为准，9个岗位中仅1个放宽至本科。

2. **专业需求表要在推图位之前**。读者一到推图位就跳出去看完整岗位表，回来路径已断。顺序应为「先概览（专业表）→ 再明细（推图位）」。

3. **两个不同的"1:3"要区分表述**。开考比例与面试入围比例常同为 1:3，第二处必须写明"面试入围比例同为 1:3"，否则读者读成一个概念。

## 三、推图位规范

**不列具体岗位明细**，改为占位引导（除非用户明确要求列全）。

| 位置 | 文案 | 用途 |
|---|---|---|
| 前言下方 | 领取岗位表 | 内部引导，读者自取岗位表 |
| 01 章末 | 领取岗位表 | 承接岗位表明细需求 |
| 全文最末 | 备考资料 | 承接转化 |

**草稿版写法**：`【插入推图｜领取岗位表】`
**排版版写法**：居中虚线占位框（🖼 + 说明文字），用 gzh-design 通用组件库的占位组件。

**合规红线**：
- 备考资料图的**图上文字**不能出现"关注领取""转发后领取""扫码进群"——属诱导关注/诱导分享，会被限流。推文正文里的占位文案保持中性即可。
- **推图位一律指向内部，不引导去源文公告**。不写"识别源文公告""识别查看官方原文""去源文取一份"这类表述。想表达"以官方为准"时，写成数据核对语境下的一句话（"数据以官方发布为准"），而不是让读者跳出去的指令。

## 四、语言规范

**要**：
- 正式而直白，用公告原文口径（"笔试主要测评**应聘人员**岗位相关专业知识"——原文的限定词不要漏）
- 数据用表格承载，不塞进长句
- 短段：每段 ≤4 行
- 关键限定词做下划线/加粗标记（`==文字==`）

**不要**：
- ❌ 开头写"XX单位于X月X日发布公告"——读者不关心发布主体与时间
- ❌ `本文看点` / `导读` 类版块
- ❌ AI 套话：`需要提醒的是`、`值得注意的是`、`综上所述`、`总而言之`、`首先/其次/最后`、`希望能帮到你`、`让我们一起`
- ❌ "一句话总结"式的概括句
- ❌ END 分割线、作者签名、"点赞在看转发"三连（除非用户要求）
- ❌ 同一句式在相邻段落重复开头（尤其"本次"——控制在 2 处以内）
- ❌ 把公告未提及的信息写成既定条件（典型：历年有加分政策，本年公告未提则不写）

---

## 五、开头写什么

第一段只回答"什么时候报名、怎么报"：

> 本次公开招聘事业单位工作人员**10名**，均为事业编制。报名采取网络报名方式，报名时间为**2026年9月17日9:00至9月22日17:00**。

用户若在意"跟读者有没有关系"，在前言加一句身份锚点，**单独成段、不加装饰块**：

> 在珠海及周边找事业编的考生，这次机会可以放进备选清单。

---

## 六、结尾写什么

停在风险提示上（如"取消报考或聘用资格"）情绪落点是负的。补一个中性收束段，**只钉日期**：

> 两个日期请务必记牢：**9月17日9:00网上报名开启**，**10月8日9:00报名确认开启**，后者漏做则报名不成功。

不要加三连话术，不要加"希望能帮到你"。

---

## 七、标题方向（爆文钩子体系）

信息完整的平铺标题（"XX区公开招聘事业单位工作人员公告"）没有点击欲。要补一个**事实型反差钩子**——**只用公告里真实存在的事实做反差，不虚构、不夸大**，这是本 skill 标题的红线。

### 7.1 标题的公式

```
【地名/系统词】+【核心事实】+【反差钩子】+【时间紧迫】（时间可省）
```

拆开看，一条能点的标题通常同时命中下面 2–3 个钩子：

| 钩子类型 | 作用 | 写法 | 例 |
|---|---|---|---|
| **门槛反差** | 制造"我够不够格"的自我代入 | 把最松/最严的门槛单独拎出来 | 不限专业 / 只要本科 / 8个岗要硕士，只有1个本科岗 |
| **身份筛选** | 精准圈人，非目标读者自动退出 | 点名受众身份 | 面向在编在岗 / 只招应届 / 面向基层服务人员 |
| **时间紧迫** | 逼出"现在就得看" | 报名起止日 + 窗口天数 | 9月20日起报名 / 只有5天 |
| **数字锚点** | 具体数字比形容词可信 | 岗位数 / 人数 / 比例 | 4人 / 2个岗位 / 1:5进面 |
| **稀缺反差** | 名额少或条件特殊 | 用"只有/仅/唯一"限定量级 | 全市仅4个名额 |

### 7.2 字数与句式

- **主标题控制在 16–26 字**（公众号列表页两行内读完，超出会被截断）
- 结构用 `｜` 或 `，` 分隔两个信息块，**不要超过 2 段**
- **前半段给利益/事实，后半段给反差或时间**——前半段决定点不点，后半段决定点了之后留不留
- 可用 `｜` 做视觉断点：`信宜事业编｜4个名额，不限专业的那个岗在招`

### 7.3 三种可直接套的句式

**（A）反差型**（信息量最大，最稳）
> `{地名}{系统}｜{反差点}，{补充事实}`
> 例：信宜事业编选聘4人｜全班要求本科，有一个岗不限专业

**（B）圈人型**（精准，适合范围受限的公告）
> `{受众身份}注意：{地名}{类型}{名额}，{时间}`
> 例：信宜在编在岗的注意：财政局选聘4人，9月20日起现场报名

**（C）紧迫型**（临近截止或窗口极短时用）
> `{时间紧迫点}：{地名}{类型}{名额}，{门槛/反差点}`
> 例：报名只有5天：信宜财政局选聘4人，本科可报、一岗不限专业

### 7.4 禁用（触发即违规/限流）

- ❌ **标题党词**：震惊、速看、不看后悔、必看、最后一次机会、重磅、太突然
- ❌ **绝对化用语**：最、第一、唯一、100%、包过（广告法红线，考编类尤其敏感）
- ❌ **编造公告里没有的反差**——反差必须能在公告正文或岗位表里指到原文
- ❌ **"公告"二字结尾**（"XX招聘公告"是公文标题，不是推文标题）
- ❌ **堆砌 emoji**（标题里最多 0–1 个，列表页 emoji 过多会被判定营销感）

### 7.5 交付时给几个

**默认给 3 个备选**，各自标明钩子类型与适用场景，让运营按当天情况挑：

```
主标题（推荐）：……
   钩子：门槛反差 + 时间紧迫
备选1：……   钩子：身份筛选
备选2：……   钩子：数字锚点 + 稀缺反差
```

标题也要做**事实核对**：地名、单位名、人数、日期、门槛，逐项对公告。曾有把"选聘"写成"招聘"的错误——两者性质不同（选聘面向在编人员），标题写错等于误导读者。

## 八、信息完整性核对（动笔前必须抓齐）

| 要素 | 位置 |
|---|---|
| 用人单位清单 | 01 章 |
| 岗位数与总招聘人数 | 01 章数据卡 |
| 学历门槛分布 | 01 章醒目处 |
| 专业需求（按量排序）| 01 章 |
| 待遇 / 服务年限 | 01 章 |
| 执业资格要求 | 01 章末 |
| 报名时间、报名方式、报名确认时间 | 02 章 |
| 开考比例、笔试内容与合格线 | 02 章 |
| 面试形式、合格线、总成绩公式 | 02 章 |
| 招聘对象、学历证书取得时点 | 03 章 |
| 年龄口径（周岁↔出生日期）| 03 章 |
| 应届生类别 | 03 章 |
| 不得报考情形 | 03 章 |

**缺任何一项都不要动笔**——回到职位表 dump 与公告原文补齐。
